## 📊 Data Visualization Lab

This repository documents my learning journey in Data Visualization through:

- College lab notebooks and assignments  
- Hands-on practice with plotting and visual analysis  
- Exploring different visualization techniques for the same data  
- Comparing outputs to understand how design choices affect interpretation  

The goal is not just to generate plots, but to deeply understand:

- how to choose the right visualization for a problem,  
- how visual encodings influence insights,  
- and how to communicate data clearly and effectively.  

This repo reflects learning in public — progress over perfection.
